# mai-kindle-images

**Kindle出版サポートIG（[@mai_kindle_supporter](https://www.instagram.com/mai_kindle_supporter/)）の投稿画像・動画の公開置き場。**

Instagram の Content Publishing API は、ローカルのファイルを受け取らず「公開URL」を要求する。
そのURLを出すためだけのリポジトリ。

- `images/` … 投稿画像（JPEG）
- `videos/` … リール動画（MP4）

⚠️ ここは誰でも見られる場所。**Instagramに出すものだけを置く**（下書き・ボツは置かない）。
⚠️ むすひ・チベスナとは別リポジトリ。**ブランドを混ぜない。**

作業場側の仕組み： `projects/Kindle出版/scripts/`
